TrueFrame: foreground export demonstrations

Candidate source: Android 0.8.1 (43). These are actual UI recordings from the isolated QA package com.trueframe.cpp.debugUnlocked, using the same ExportService/export implementation as the candidate. They demonstrate the media-export feature; they are not a claim of Play-installed licensing acceptance. Only synthetic colour-bar media is shown. No account credentials or personal media are included.

The user chooses Save playback clip, confirms Save MP4, and TrueFrame transcodes the selected local WebM/VP8 file into a new MP4/H.264 file. The Exports screen reports completion and offers the saved copy. The source is retained. Jobs can be cancelled from Exports while active. Android 11?14 selects dataSync; Android 15+ selects mediaProcessing. No media upload or cloud sync is performed by ExportService.
